Bypass is a simple browser proxy experiment.  

## What's a Browser Proxy?  
A browser proxy is like a little browser that runs in your browser! It's a fun (and legal) way to experiment with simple backend code. This browser proxy, Bypass, is very simple compared to many others; it is limited to static functions and does not support dynamic displays.  

## Using Bypass  
Use this web app [here](https://kpoovakan.github.io/bypass/).
| Keyboard Shortcut | Result |
| :---------------: | ------ |
| CTRL + ALT + F | Jump to URL input bar |
| CTRL + ALT + R | Clear the URL input bar |
| CTRL + ALT + D | Enable [developer mode](#developer-mode) |
| CTRL + W | Close Bypass |

## Developer Info  
Due to the simple backend, Bypass will display sites as a static page. Interaction is disabled, as clicking on links will break out of the proxy. All other interactions with the site would likely fail.

## Developer Mode  
Use CTRL + ALT + D to enable site interactions. Right-click on any link and select "copy link" from the drop-down menu, then use other [keyboard shortcuts](#using-bypass) to quickly navigate back to the URL input bar. Paste the copied link into the URL input bar to view the new webpage.  
**Directly clicking the links or interacting with the webpage will break out of the proxy.**
