Bypass

kpoovakan source

Bypass is a simple browser proxy experiment for static site viewing. Enter the URL of any site with its HTTP (or HTTPS) and read the contents of the site. Simple static pages (like blogs) will load just fine, but complicated dynamic pages won't load correctly.

Clicking on links breaks out of the proxy, so enable developer mode to copy links and paste them back into the URL area. View the README for more info regarding developer mode.
